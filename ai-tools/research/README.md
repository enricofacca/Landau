# Research record

This directory is the persistent scientific memory shared by the human, coding agents, and advisor.

- `program.toml`: global goal and project-wide criteria
- `stages/`: one durable development phase at a time, each with technical note + development plan + baseline
- `studies/`: one stable directory per hypothesis
- `competitions/`: common rules/evidence for competing tracks
- `reuse/components.toml`: reusable experimental/prototype asset registry
- `LOG.md`: chronological events
- `STATUS.md`: generated dashboard; do not hand-edit
- `DECISIONS.md`: reviewed cross-study decisions
- `advice/`: advisor review history and `LATEST.md`

Failed, inefficient, falsified, superseded and outcompeted approaches remain traceable. Artifact retention is recorded separately from scientific status.
